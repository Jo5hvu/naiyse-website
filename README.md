# Naiyse Apparel landing page

Vercel-ready starter website built from the supplied Naiyse catalogue.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

Import this folder as a new Vercel project. Framework preset: Vite; build command: `npm run build`; output: `dist`.

Before launch, replace the placeholder email in `index.html` with Naiyse's real WhatsApp number or email.
